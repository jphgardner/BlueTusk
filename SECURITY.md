# Report a security issue

Contact the repository maintainers privately. Use GitHub’s private
vulnerability reporting if it is available for the repository. Keep report
details out of public issues.

Include the affected package and version, the impact, and a minimal
reproduction when safe. Remove connection strings, credentials, bearer
tokens, tenant identifiers, customer data, and production logs from the
report.

See [application security](docs/security.md) for TLS, PostgreSQL roles,
tenant isolation, and safe telemetry.
