Status: published on 2026-08-23.

from release commit
[`7380d7b028c72b2aae348b778711d104d022a3f8`](https://github.com/jphgardner/BlueTusk/commit/7380d7b028c72b2aae348b778711d104d022a3f8).

release exception was removed by
[`6abb6365f1352fbb6d24a76d67f42d567800782b`](https://github.com/jphgardner/BlueTusk/commit/6abb6365f1352fbb6d24a76d67f42d567800782b)

## Repository-owner release decision

The repository owner explicitly authorised immediate stable publication and
accepted the following exceptions to the planned V1 evidence policy:

- independent approval was incomplete;
- coverage-guided fuzz evidence was not produced for the release commit;
- the reference performance gate had not passed;
- the exact endurance evidence was incomplete; and
- PostgreSQL 19 GA evidence was deferred.

These exceptions are release facts, not successful gate results. They do not
change the standard release policy for later versions, and they do not turn
the missing evidence into a production-readiness claim. No coverage-guided
fuzzing workflow was triggered as part of this release operation.

## Post-release obligations

The published artifacts are immutable. A defect is corrected with a new
version; `1.0.0` is never overwritten. The deferred PostgreSQL 19 GA matrix,
endurance runs, reference performance evidence, independent review, and pilot
evidence remain open hardening work and must retain their real status in all
future readiness claims.
