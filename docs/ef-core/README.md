# Entity Framework Core

`BlueTusk.EntityFrameworkCore` is the EF Core provider over the BlueTusk ADO.NET driver. The current 0.2 implementation supports provider registration, relational queries, change tracking and PostgreSQL CRUD, explicit transactions and savepoints, store-generated values, optimistic concurrency, and the core PostgreSQL scalar type mappings.

## Configure a context

```csharp
services.AddDbContext<AppDbContext>(options =>
    options.UseBlueTusk(connectionString));
```

`UseBlueTusk` also accepts an existing `BlueTuskConnection` when the application owns connection construction or lifetime.

## Current migrations support

`Database.GenerateCreateScript()` and `IRelationalDatabaseCreator.CreateTables()` generate PostgreSQL DDL for ordinary relational models. The supported create-schema surface includes tables, primary and foreign keys, indexes, defaults, length and precision facets, and `GENERATED BY DEFAULT AS IDENTITY` integer keys. This path is covered both by SQL-shape tests and by executing the generated commands against PostgreSQL.

The migration history repository, idempotent scripts, alter/rename operations, design-time migration tooling, and reverse engineering remain in progress. See [the executable roadmap](../roadmap.md) for the exact status; do not treat the package boundary as a claim that those surfaces are complete.
